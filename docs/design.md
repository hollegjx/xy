# 界面风格

- 类型：作品类（面向用户的 AI 应用生成平台）
- 风格：黑白 · 简约（mono-apple-ui）；近黑 #1d1d1f、浅灰画布 #f5f5f7、白色卡片，彩色只用于错误（#d70015）
- 生成模式靠黑 / 深灰 / 浅灰描边区分，不用彩色渐变；成功、信息提示与状态点同样用黑白
- 圆角：输入框 12px、卡片 18px、面板 24–28px；按钮一律胶囊形；输入框为半透明黑填充，聚焦变白底加近黑描边
- 密度：控件 40px；内容最宽 1160px，表单最宽 680px
- 意象：星点与连线；口号「让灵感在此成形」；品牌标识为近黑圆角方块中的白色四角星
- 顶栏：毛玻璃；分段式导航，白色滑块按当前页弹性移动；手机端账号区只留头像
- 首页：通栏白色首屏（粒子背景、标题四行依次入场、悬浮表单卡片）→ 循环演示窗（HomeDemo.vue，12 秒：描述需求 → 实时生成 → 选中元素改深色 → 发布）→ 我的应用 / 精选作品 → 黑色流程区（滚动揭示）
- 粒子：首页首屏与流程区自带；其他页面铺在视口背后（BasicLayout），工作台不加
- 动效：入场与悬停 cubic-bezier(0.22, 1, 0.36, 1)，按压、弹出、导航滑块 cubic-bezier(0.34, 1.56, 0.64, 1)；页面区块依次上浮（720ms，错开 70ms），卡片悬停上浮 4px，按钮按下缩到 0.97；尊重减少动态效果设置（演示窗直接显示最终状态）
- 在 .vue 中使用浏览器全局对象时写 globalThis.xxx（ESLint no-undef）
